The assets are checked in so recipe imports remain reproducible without
downloading external images at import time. The additional audited assets are
declared next to their recipe, creator, source file, and license in
`scripts/import-howtocook.mjs`. Running `pnpm run images:optimize` copies that
attribution into `IMAGE_INVENTORY.md`, including whether an image was
focus-cropped to remove unrelated content.
